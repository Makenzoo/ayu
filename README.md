# Сайт университета Ясауи

Откройте эту папку в Visual Studio Code. Основные файлы находятся в `dist/`:

- `index.html` — структура страницы и тексты;
- `styles.css` — цвета, размеры и расположение элементов;
- `translations.js` — тексты на казахском, турецком, английском и русском;
- `script.js` — переключение языков, вкладок и меню;
- `assets/` — фотографии, логотипы и значки.

Папка `assets/` в корне проекта содержит старый исходный файл; страница
использует изображения из `dist/assets/`.

Чтобы посмотреть сайт локально, откройте терминал в VS Code и выполните:

```bash
python3 -m http.server 4173 --directory dist
```

Затем откройте `http://127.0.0.1:4173/` в браузере. Сервер останавливается
сочетанием `Ctrl+C` в терминале.

Код отформатирован с шириной строки около 80 символов. Длинные адреса,
SVG-контуры и некоторые тексты остаются длиннее, чтобы не менять их содержимое.
